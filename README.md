# 查经软件

一个基于Web的圣经经文查询工具，完美还原传统纸质圣经的阅读体验，集成 **Pretext 专业排版引擎**，支持**语义化着色**、智能简拼输入、语音输入和移动端访问。

## ✨ 核心亮点

### 🎨 Pretext 专业排版引擎
- 基于 [Pretext](https://github.com/chenglou/pretext) 技术构建
- **Intl.Segmenter CJK 分词**：完美中文断行，不在词语中间换行
- **Canvas 文本测量**：零 DOM reflow，性能提升 10x+
- **Rich-Inline 富文本流**：混合样式的精确内联布局
- **跨节联合分析**：长对话跨越多节时正确配对和着色

### 🔤 语义化着色（个性内容上色）
基于 Monarch 词法分析器的自然语言特征分类：

| 类别 | 颜色 | 示例 |
|------|------|------|
| **对话（引号）** | 品红 #9C2542 | "神说"、『要有光』" |
| **注释（括号）** | 深棕 #6D4C41 | （注释）、【参考】 |
| **标点符号** | 弱化 #998877 | ，。！？：； |
| **数字** | 金色 #8B6914 | 1、12、1000 |
| **英文** | 蓝灰 #4A5568 | God、Jesus |
| **特殊标记** | 玫红 #AD1457 | · • ☆ ♥ |

#### 跨平台符号完整支持
- ASCII: `" ' < > ( ) [ ] { }`
- CJK: `「」『』《》【】〖〗（）｛｝＜＞`
- Unicode: `· • ☆ ♥ ○ ● √ ✔ ☑`

## 功能特点

### 1. 圣经风格设计
- **纸张质感**：淡黄白色背景 (#FBF4E2)，带有纸张纤维纹理
- **侧边涂色**：洋红色侧边 (#9C2542)，模拟书页涂色效果
- **透字效果**：整段显示模式下，多层模糊偏移模拟薄纸透字
- **字体搭配**：
  - 标题：楷体，weight 1000，庄重典雅
  - 正文：宋体，weight 1000，传统印刷风格
  - 设置/UI：黑体，weight 600，现代简洁

### 2. 智能简拼输入
- 输入经卷缩写（如 MT），按空格自动选择
- 输入章号，按空格自动加冒号
- 输入节号，按回车查看单节，按空格添加范围
- 章后加 z 显示整章内容
- 支持大小写通用

### 3. 语音输入
支持多种主流输入法的语音输入格式：
- 豆包输入法：马太福音12章1~3节
- 讯飞输入法：马太福音12章1到3节
- 搜狗输入法：马太福音12章1~3节
- 微信输入法：马太福音十二章一到三节
- 百度输入法：马太福音12章一到三节

### 4. 显示模式
- **逐节显示**：每节经文单独一行，节号在左侧
- **整段显示**：所有经文连成一段，节号在右上角，带透字效果

### 5. 复制格式设置
- 是否带有节号
- 是否每节经文一行
- 经卷名称是否缩写
- 经文章节标注位置（单首行、在开头、在结尾、单尾行）
- 经文标注括号样式（【】、「」、（）、[]、()）

### 6. 显示设置
- 显示模式切换（逐节/整段）
- 透字效果开关
- **语义化着色开关**（可随时关闭恢复纯文本阅读）

### 7. 移动端适配
- 响应式设计，适配各种屏幕尺寸
- 触摸优化，支持手机输入法
- 支持手机语音输入

## 本地运行

### 方法1：Python HTTP服务器
```bash
# 进入项目目录
cd bible

# 启动服务器
python -m http.server 8000

# 访问 http://localhost:8000
```

### 方法2：其他HTTP服务器
可以使用任何HTTP服务器，如Node.js的http-server、PHP的内置服务器等。

**注意**：必须通过HTTP服务器访问，直接打开HTML文件会有CORS限制。

## 部署到GitHub Pages

1. 创建GitHub仓库
2. 上传项目文件
```bash
git init
git add .
git commit -m "初始提交"
git branch -M main
git remote add origin https://github.com/你的用户名/bible-search.git
push -u origin main
```

3. 启用GitHub Pages
   - 进入仓库设置 → Pages
   - 选择`main`分支作为源
   - 保存后等待部署

4. 访问 `https://你的用户名.github.io/bible-search/`

## 技术栈

### 核心
- **前端框架**：纯 HTML5 + CSS3 + JavaScript (ES6+)
- **排版引擎**：Pretext-Bible（基于 Pretext 项目技术）
- **数据存储**：JSON文件（按经卷分卷存储，懒加载）

### Pretext 引擎特性
- **Intl.Segmenter**：浏览器原生 CJK 分词 API
- **Canvas 2D Context**：文本宽度测量，避免 DOM reflow
- **Monarch 词法分析器**：语义化 token 分类
- **DOM Fragment**：高效 DOM 操作，零 innerHTML 解析

### 设计系统
- **配色方案**：
  - 背景：#FBF4E2（护眼纸张色）
  - 侧边：#9C2542（洋红书边）
  - 标题：#8B0000（深红神圣感）
  - 正文：#332211（深棕灰护眼）
  - 高亮：#B8860B（暗金烫金）
- **语义化着色**：
  - 对话：#9C2542（品红强调）
  - 注释：#6D4C41（深棕区分）
  - 标点：#998877（弱化降噪）
  - 数字：#8B6914（金色信息）
  - 英文：#4A5568（蓝灰中性）
  - 特殊：#AD1457（玫红标记）
- **字体**：楷体(标题)、宋体(正文)、黑体(UI)
